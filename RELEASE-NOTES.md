# TOTP Bridge 1.0.0

Download **TOTP-Bridge.html** from the release assets and open it directly in a modern browser. No installation, webserver or Internet connection is required to use the app.

- Import Authy GDPR CSV, Ente and Aegis backups, and Passbolt/KeePass KDBX.
- Reveal setup keys and QR codes after confirmation; preview current and next OTP codes.
- Optional HOTP, Steam and mOTP compatibility, with explicit export compatibility checks.
- Export encrypted Ente/Aegis/KDBX backups or acknowledged plaintext.
- Embedded English guide, architectural notes and library license notices.

All processing takes place locally. See the embedded guide for format limitations and verification steps before removing an original authenticator.
